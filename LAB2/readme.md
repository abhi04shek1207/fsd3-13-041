# FS (File System) Node JS's Module
it direct connect with client os rater than browser
## Major task of FS Module
 - Reading and writing files
  - readfile()
  - writefile()
  - appendfile()

- Directory Mangement
  - mkdir()
  - rmdir()  - depricated
  - rm()
  - readdir()

- Metadata/ Information
 - stat()
 - lstat()
 - fstat

- Watching for Changes
 - watch()
 - watchfile()
 - unwatchFile()

- Streaming Large File
 - createReadStream()
 - createWriteStream()
  
- File Operations
   - rename()
   - truncate()
   - unlink()
   - link()
   - syslink()
